# My Fitness Prime

Aplicación web de nutrición y seguimiento personal.
Calcula un objetivo diario de calorías y macros, registra
lo que como durante el día y muestra si mi evolución va
en la dirección esperada.

## Qué hace hoy

- Onboarding en 5 pasos con 5 objetivos, incluida recomposición
- Pantalla Hoy: objetivo, consumido, restante y progreso de macros
- Registro por comidas: desayuno, almuerzo, cena y snacks
- Pantalla Progreso: peso, promedio de 7 días y adherencia
- Base de alimentos y conversor de peso crudo a cocido

## Qué falta

- Persistencia: los datos se pierden al cerrar la pestaña
- Motor de calibración: calcular el gasto real desde peso e ingesta
- Platos guardados para no registrar ingrediente por ingrediente
- Backend, base de datos y despliegue

## Estado

Prototipo. Proyecto de aprendizaje.
